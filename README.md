# Clínica Salud Vital

Proyecto desarrollado para el curso de Taller de Programación Web.

## Descripción

Esta página web presenta parte de los procesos de la Clínica Salud Vital, específicamente las áreas de Admisión y Consultorio.

### Admisión
Se encarga del registro de pacientes y la gestión de citas médicas.

### Consultorio
Permite representar la atención médica y el registro de información relacionada con la historia clínica del paciente.

## Tecnologías utilizadas

- HTML5
- Etiquetas semánticas
